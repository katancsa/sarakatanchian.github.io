# Sara Katanchian academic website

A lightweight static academic website designed for GitHub Pages.

## Publish with GitHub Pages
1. Create a GitHub account/repository named `sarakatanchian.github.io` (or `<your-github-username>.github.io`).
2. Upload everything in this folder to the repository root.
3. In GitHub: Settings → Pages → Source: Deploy from a branch → `main` / root.
4. Your site will appear at `https://<your-github-username>.github.io/`.

## Before publishing
- Replace the SK circle on the home page with a professional photo if desired.
- Confirm that the CV in `assets/Sara_Katanchian_CV.pdf` is the academic CV you want public.
- Confirm that the JMP PDF is the version you want publicly available.
- Add LinkedIn/ORCID/department-profile links if desired.
- Add a PDF link for the JRSS-A R&R only if you want that draft public.
